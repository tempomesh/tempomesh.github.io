What you can do

Built for real workflows.

8mem ships with a full command set and REST API. Use it from the terminal, Telegram, or wire it directly into any AI runtime.

/passport

Your memory passport

See the active memory an agent is using right now, including saved context and trust checks.

8mem /passport
→ memory status
→ saved memories and corrections
/compare

Generic vs memory-aware output

Compare what an agent says without memory against what it can do with 8mem context attached.

8mem /compare investor update
→ without memory
→ with 8mem
8mem correct

Fix what's wrong, keep the history

Tell 8mem something is incorrect. It archives the old belief with a timestamp and writes the new one. Nothing is silently deleted.

You: "I moved to London, not Berlin"
→ Berlin archived (was: 94%)
→ London saved (now: 99%)
8mem forget

Remove anything, on demand

You are always in control. Tell 8mem to forget a belief and it is removed from active memory — you stay the source of truth.

You: "forget my dietary prefs"
→ 2 beliefs removed
→ audit entry created
GET /v1/context

Runtime injection API

Any AI runtime calls one endpoint and receives your full context as a structured envelope — ready to inject into any system prompt.

curl /v1/context
→ identity, beliefs, history
→ system_prompt_injection ready
8mem doctor

Health check in one command

Verify every component — memory server, context API, agent hooks, runtime connections — with a single command. Green means ready.

8mem doctor
✓ memory server running
✓ all hooks connected
