Install 8mem on your machine.

Agent memory your AI can finally keep. Visible. Correctable. Portable. Shared. Start with the browser UI, add Telegram when your bot/webhook is ready, and connect OpenClaw or Hermes later if you use them.

Quick install Setup choices Troubleshooting
Option A

Install with curl

Best for Raspberry Pi, Linux boxes, and quick local installs. It creates a private 8mem runtime under ~/.8mem.

Option B

Install with pipx

Best for users who already use Python CLI tools. It installs the public PyPI package and keeps it isolated.

Before you start

What you need

2-10 minutes
  • Python: Python 3.10+ installed.
  • Browser UI: no Telegram, OpenClaw, or Hermes required.
  • Local model chat: optional Ollama install. Use any model you have pulled; examples like qwen3:1.7b are placeholders, not requirements.
  • Telegram: optional BotFather token plus a public HTTPS webhook URL such as ngrok, Tailscale Funnel, or your own domain.
  • OpenClaw/Hermes: optional. If you install them after 8mem, rerun the relevant 8mem setup command later.
1

Curl install

curl -fsSL https://8mem.com/install.sh | bash

The script installs the current public wheel, initializes ~/.8mem, runs doctor, and prints exact next steps. If setup is incomplete, it should say what is missing instead of pretending everything is ready.

2

Pipx install

python3 -m pip install --user pipx python3 -m pipx ensurepath pipx install 8mem 8mem setup

Open a new terminal after pipx ensurepath if your shell cannot find 8mem.

3

Choose how to use 8mem first

8mem setup
Browser UI onlyRecommended first. Save memory, inspect memory, import conversations, and test local memory without Telegram.
Telegram botUse this when you already have a BotFather token and a public HTTPS webhook URL.
Browser UI + TelegramFull product path: local dashboard plus Telegram commands like /passport and /compare.
Agent integrationsAdd OpenClaw or Hermes only if those runtimes are installed on the same machine.
4

Start and open

8mem doctor 8mem start 8mem status

Then open http://127.0.0.1:8787 on the same machine.

Browser UI

What works without Telegram

  • Save a fact from Start Here.
  • Review what AI knows.
  • Inspect and edit memory sections.
  • Import conversations or use sample data.
  • Test local memory if Ollama is installed.
Telegram

What Telegram needs

  • BotFather token.
  • Public HTTPS webhook URL that forwards to your local 8mem server.
  • Run 8mem setup --mode telegram after the public URL is ready.
  • Test with /start, /passport, and /compare topic.
Later: OpenClaw

If OpenClaw is installed after 8mem

8mem setup --mode openclaw

This adds the 8mem memory hook/config for OpenClaw. It does not uninstall or replace OpenClaw.

Later: Hermes

If Hermes is installed after 8mem

8mem setup --mode hermes

This adds the 8mem memory integration for Hermes. It does not uninstall or replace Hermes.

Command not found

Fix your PATH

export PATH="$HOME/.local/bin:$PATH" 8mem doctor # Curl install fallback: ~/.8mem/venv/bin/8mem doctor
Wrong Ollama model

Choose a model you actually have

ollama list 8mem setup --llm-model YOUR_MODEL_NAME

Model names in docs are examples only. 8mem should work with the local model you choose.

Telegram webhook missing

Add it after tunnel setup

8mem setup --mode telegram 8mem doctor
Clean uninstall

Remove package, keep or delete memory

8mem stop pipx uninstall 8mem # Optional only if you want to delete local memory: rm -rf ~/.8mem

Apps normally keep user data unless the user explicitly deletes it.

Verify

When install is ready

PASS
  • 8mem doctor reports core checks as pass.
  • 8mem start starts the server.
  • http://127.0.0.1:8787 opens the local dashboard.
  • Browser-only users can save and inspect memory locally.
  • Telegram users configured a real bot token and webhook URL.
8mem public install guide. Keep local API keys, Telegram tokens, and webhook secrets private.
